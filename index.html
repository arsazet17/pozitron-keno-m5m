v0.1.0-M5M

M5M

Независимый клон стабильного M4. Здесь можно менять и добавлять новый алгоритм, не затрагивая рабочее M4.

Строгие правила

4 метода считаются только по основному архиву. Первичная цепочка сокращается 6→5→4… только слева до первого совпадения. Вариант 1: охват методов → общая частота → глубина цепочек. Вариант 2 и Доп. Г/Г при ничьей сокращаются ровно на одну длину за раунд. Свежесть и давность совпадений не используются как критерий.

Сканер

Сканер проверяет только столбы, уже выданные текущим прогнозом. Новые столбы сканер не добавляет. Временная рекомендация строится по историческому бэктесту тех же строгих правил для трёх совпадений: В1+В2+Доп., В1+В2 и В1+Доп.

Навигация

Переход между страницами работает только нижними кнопками. Свайп между страницами отключён.
